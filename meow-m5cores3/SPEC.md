# Meow-M5Cores3

## 概要

ShapoGFX の 2D リグアニメーションの簡単なサンプル。
画面に子猫のアニメーションが表示され、それをタップするとフキダシで「Meow」と表示される。

## 仕様

### プラットフォーム

- M5Stack CoreS3
- ESP-IDF 5.5
    - 環境変数 `IDF_ROOT` でパスを指定。デフォルトは `${HOME}/esp/5.5/`
- M5Unified/M5GFX : タッチ入力、ディスプレイへの転送、その他プラットフォーム依存の処理に使用
- ShapoGFX : 2D リグアニメーションとフキダシの描画に使用
    - 環境変数 `SHAPOGFX_PATH` でパスを指定。デフォルトは `${HOME}/sgfx/shapo-gfx/`

### アニメーション素材

- `assets/kitty/` 配下のアーマチュアおよびアニメーションを ShapoGFX の `dbones2cpp` で C++ コードに変換して include する。
- `dbones2cpp` の使用方法は ShapoGFX のドキュメントを参照。サンプルプロジェクトの `demorig` も参考にする。
- `--scale 0.5` で 50% にスケーリングする。
- `kitty_ske.json` 自体にも `idle` / `meow` が入っているが、`kitty_idle.dbani` / `kitty_meow.dbani` の同名アニメーションが置き換える (警告が出るが問題ない)。
- 異なる名前で次の 2 通り作成する:
    - 低速版: スケーリングオプション以外はデフォルトの設定で生成したもの (ARGB4444 のアトラス)。
    - 高速版: スケーリングに加え、`--atlas-width 0 --fit-rotate --out-format rgb565_swapped` で最適化したもの (画像ごとのテクスチャ、キーカラー、フレームバッファと同じ形式)。
- 生成された C++ ソースもコミット対象にする。

### 機能

- ピクセルフォーマットは RGB565_SWAPPED で統一する (フレームバッファもテクスチャも)。
    - M5GFX の `writePixelsDMA(..., swap = false)` にバッファをそのまま渡せるバイト順で、DMA 転送中に CPU が空く。ネイティブ RGB565 を渡すと M5GFX が CPU でバイトスワップしながら送るため、描画と転送を重ねられない。
    - テクスチャも同じ形式にすると、変換なしのコピー経路 (キーカラー付きコピー) で描画される。
- 背景は灰色一色。
- 待機モーション: 画面下端、右から 1/3 ほどの位置で kitty の idle アニメーションをループ再生する。
- タップモーション: 画面をタップすると kitty の meow アニメーションを 1 回再生し、同時に 1 秒間だけフキダシで「Meow」と表示する。meow アニメーションは 2 秒で完了するので、その後待機モーションのループに戻る。
    - meow の再生中にもう一度タップされたら、meow とフキダシを最初からやり直す。
    - meow の最後の姿勢は idle の最初の姿勢と同じなので、idle はフレーム 0 から再開する。
- フキダシは kitty の左上に、白く塗りつぶされた角丸の矩形と三角形を組み合わせて表示する。縁取りはしない。文字はピンク色。
- 画面の左上隅に FPS を表示する。
- 上記以外の描画は不要。

## 実装

- main.cpp にプラットフォーム依存の処理を、scene.cpp にアニメーションの描画処理を実装する。
- マジックナンバーは避け、定数として定義する。
- 画面サイズなど、プラットフォームから取得できるものはそれを使用する。
- 次の 2 通りの実装を行い、マクロで切り替える (デフォルトは高速版)。
    - 低速版: 低速版の kitty を使用 + シングルバッファ
    - 高速版: 高速版の kitty を使用 + ダブルバッファ
        - 内部 SRAM には 2 面分のフレームバッファを持てないので、画面を上下に分割して描画と転送を同時に行う。
        - 描画は 1 コアで行う (demorig のような 2 コア分割はしない)。
- PSRAM は極力使用しない。
- 入門者向けなので、読みやすいように実装し、コメントも適宜追加する。
- ShapoGFX のサンプルプロジェクトの `demorig` も参考にする。
